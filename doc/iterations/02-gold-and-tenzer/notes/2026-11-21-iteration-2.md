# Iteration 2: typesetting Gold's Jaya Semara and Tenzer's Baris

Status: agreed scope (2026-11-21). The design to build next. Nothing
here is implemented. ADRs and the changes to `doc/design/` follow from
it, when the design is turned into work.

## Goal

Typeset two published examples, faithfully in content and close in
layout:

| Target | Source | File |
|---|---|---|
| Jaya Semara, pangecet: one gong cycle | Lisa Gold, *Music in Bali* (2005), activities 2.4, 3.1, 3.2, figure 3.1 | `../targets/2026-11-21-jaya-semara-pangecet.nts` |
| Baris (gilak): one gong cycle, with sung lines | Michael Tenzer's notation of reyong and kendang parts | `../targets/2026-11-21-baris.nts` |

The two stress different things. Jaya Semara tests the music: many
layers at different densities, quarter-pulse kotekan built from
patterns, a 16-pulse colotomy with a pickup, our coloured grid.
Baris tests the score: syllables instead of colours, one row per part,
the drums by hand, beats numbered with the gong as 1, sung lines and a
composite line.

**Acceptance test.** Both files read without errors, every score in
them is drawn by `notasi render FILE --score NAME`, and the drawings
show what the sources show (checked by eye against the books, and by
golden tests from then on).

Many questions stay open. Anything neither target needs is "later":
designed so that it can fit, not built now.

## What is built in this iteration

### Music (language note)

- Time in kempli pulses; durations as a suffix (`e2:2`, `o3:1/4`),
  carried over until changed; a part starts at 1 pulse.
- `_` holds (Gold's cipher dot); `-` is a rest, the note damped.
- Notes by name (`e2`) or key number (`5`); chords `(2 5)`.
- `(rep N ...)`; `|` pulse checks and `||` cycle checks.
- Patterns: `(pattern NAME :short S :long L ...)`, used as `@NAME` or
  `(@ NAME :step N :short S :long L)`.
- Colotomies with a generated gong part, `:colotomy` and `:pickup` on
  the piece; the kempli implied.
- `(part INSTRUMENT :name NAME ...)`; options as `:key value`.
- Degrees and strokes with `:alias`, `:display` and `:damped` forms.
- The step derived by layout; time stored as exact rationals.

### Score (score note)

- `(score NAME ... (group LABEL ... PART ...))`, several per file; parts
  not in a score are not printed; groups only inside scores.
- Labels long and short, `:labels`; row labels for parts.
- `:rows notes/parts/single`.
- `:note-names`, `:fill colour/none`, `:holds none/dash`, open and
  damped name forms.
- `:pattern-names`, `:pattern-level`: names written over the notes.
- `:cycle-numbers`, `:pulse-numbers`, `:numbering gong-last/gong-first`,
  `:pulse-label`.
- `:title`, `:subtitle`, `:caption`; `:from`, `:to`;
  `:system-length`, `:breaks`.
- `:scheme`, `:palette`, `:colors`; `:font-size`, `:cell-width`,
  `:cell-height`.

### Pipeline (internal representation note)

- Read forms, resolve definitions, expand parts (`(notasi expand)`),
  piece, `layout-score`, JSON version 2, Typst template.

## Decisions

Every question left open in the notes, settled for this iteration.
"Later" means not built now.

### Music

| Question | Decision |
|---|---|
| Carry-over durations | Yes. |
| Rests | `_` holds (the note keeps sounding), `-` damps. Gongs never damped (`:damped no`): later. |
| `·` | Dropped. It means a rest today, but Gold's dot means a hold, so it would mislead. |
| Repeats | Every repetition is identical (LilyPond's way): the body is expanded once, with the duration in force before the `rep`, and copied. After the `rep`, the duration is the body's last. This replaces "durations carry over between repetitions". |
| The Jaya Semara meter | Defined in the piece as `pangecet-16`; not added to the template. |
| Gong strokes | One `gong` instrument with strokes `G` (gong wadon), `GL` (gong lanang), `P` (kempur), `T` (klentong). `GL` can display as "G" (Baris). |
| Generated parts | The timekeeper is the part `kempli`; colotomy parts keep the names their colotomy gives them (`gong`). |
| Reserved list heads | `rep` and `@`. No degree or stroke may be called either. |
| Piece length | The pickup plus whole cycles. The pickup is a whole number of pulses, at most one cycle. |
| Error positions | `cycle C, pulse P`, with a fraction written `4 1/2`; `pulse P` without a colotomy. An error inside a pattern names the whole chain of uses, with the line of each form. |
| Dropping notes | `:drop-first N` cuts everything before the next note kept; `:drop-last N` cuts from the first dropped note to the end. Neither target uses dropping or `:octave`: both later. |
| Names at a pattern's use | `(@ NAME :short S :long L ...)` replaces the pattern's names for that use. Jaya Semara needs it, so that moved figures are named after their pokok tone. |
| Damped name forms | `:damped STRING` on degrees and strokes. |
| Shared octave numbers | Yes: `o2` is the same pitch on every instrument. `templates/gong-kebyar.nts` is corrected to Gold's figure 2.7: the reyong becomes e2 to u4 (it is e1 to u3 today). Instruments the targets need and the template lacks (jegogan, jublag, panyacah, pemade, calung, the two kendang) are defined in the pieces for now. |

### Score

| Question | Decision |
|---|---|
| Default score | Without `--score`, the first score in the file. A file with no score gets the default score (every part in its own group). |
| How exactly to copy Tenzer's layout | The same information arranged the same way. Instrument pictures, "etc." at line ends, colons after labels and side-by-side systems: later. |
| `:rows parts` or `single` without names | An error: such rows show pitch only by name, so the group needs `:note-names yes`. `:fill none` needs it too. |
| Open and damped forms | By the grid: damped if a note lasts no longer than one column, open otherwise. It gives every syllable of Tenzer's figure. Marking damping in the music: later. |
| Pattern names over notes | Near-black text on a small white, slightly transparent box, centred over the span and over the group's rows. |
| Identical pattern names from several parts | Merged into one. |
| Different pattern names from parts of one group, overlapping | An error, naming the parts and the position. |
| Note names and pattern names in one group | Allowed: the pattern name is drawn on top. |
| Pattern levels | One level at a time (`:pattern-level`). |
| Pattern names across a system break | The name is written again on the continued piece. |
| Cycle numbers | Once, at the start of each cycle. |
| Systems one cycle long (`:system-length (cycles 1)`) | Later; `:breaks` covers the targets. |
| `(text STRING)` | Out of the notation; captions are `:caption`, and documents (06) do the rest. |
| An empty group label | Allowed (Baris's kempli and gong block has row labels only). |

### Internal representation

| Question | Decision |
|---|---|
| Time in the piece | Exact rationals in pulses. Layout chooses the step per score. |
| Expansion | Its own module, `(notasi expand)`, between the reader and the piece. |
| Pattern spans | Kept in the piece, with the names in force at each use. `rep` spans: later. |
| Score settings | Filled in by the reader: every group carries its effective settings. |
| How a note ends (`ending` field on events) | Later; the open and damped forms come from the grid. |
| The default score | A stored `score` record, built by the reader. |
| JSON | Version 2, as sketched in the score note, plus the fields for rows and captions. |

## What changes in the existing design

When this is turned into work:

- **ADRs**: new ones for time in pulses (narrowing 0002, replacing the
  `steps-per-pulse` option of 0009), scores (groups move into scores,
  `show-names` goes: 0019's default changes), options as `:key value`,
  `(part INSTRUMENT ...)`, patterns, colotomies, the `·` rest dropped,
  the palette chosen in the score (0021), and the JSON contract version
  2.
- **`doc/design/`**: 01 replaced by the language note and the score
  note; 02 by the records of the internal representation note; 03
  gains the expansion stage and the new errors; 04 becomes
  `layout-score`; 05 gets contract version 2 and the template changes;
  06 names scores.
- **Templates**: the reyong range; the gong strokes `G GL P T`.
- **Examples and tests**: `examples/tenzer1.nts` rewritten (it is the
  same cycle as Baris's ugal and gongs); the two targets added as
  examples with golden files per score; the manual updated.
- **Build order**: a new milestone, in slices, in
  `doc/design/README.md`.

## Later

From the notes, not needed by the targets: `relative` mode; `(* M ...)`
and chord durations; `:octave`, `:drop-first`, `:drop-last`; lines in
long cycles; departing from or changing the colotomy, sections; longgor
forms and other meters; another timekeeper or its own pattern;
`:damped no` for gongs; an `ending` field; patterns with parameters;
patterns written in degrees only; a level above groups; tagged versions;
more colour schemes; instrument pictures and other details of Tenzer's
look; systems by cycles.
