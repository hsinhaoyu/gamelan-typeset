# 0028 _ holds, - damps, and · is dropped

Status: accepted (2026-11-21)

Context: v1 left open whether a rest damps the previous note (01, open question 2), and accepted `·` as a synonym of `-`. Gold's cipher dot means an empty beat on which the note keeps sounding, and in kotekan each player damps so that the partner's note sounds.

Decision: `_` holds: the previous note keeps sounding. `-` is a rest: nothing is struck and the previous note is damped. Both take the current duration (`-:3`). `·` is dropped, because Gold's dot is a hold and a dot-like rest would mislead anyone copying her cipher.

Consequences: The notation now says what a player needs to know. Gongs are never damped, so in a gong part `-` only means nothing new is struck; an instrument option for that (`:damped no`) is later, as it changes what sounds, not what is drawn. v1 files that use `·` are rewritten.
